The simple rules for using Scam Shield.

By using this site or calling our test line, you agree to these terms. We kept them short.

Last updated October 28, 2026

It's a demo

Scam Shield is a hackathon project, not a finished product or a paid service. It can be offline, change, or lose demo data at any time.

It helps, but it's not a guarantee

Scam Shield uses AI to spot scam tricks, and AI can be wrong. It can miss a scam, or warn about a call that's fine. Always double check before sending money or sharing personal numbers, and call your family member back on a number you already know.

Not for emergencies

Scam Shield isn't an emergency service. If someone is in danger, call 911.

Only use it with everyone's OK

  • Only sign someone up if they agree. Scam Shield asks them for a YES on their own phone before it listens.
  • Only add Scam Shield to a call, or use the test line, when everyone on the call knows and agrees. Scam Shield says out loud that it's listening.
  • Don't use the test line to harass anyone or to test real people without their OK.

Play fair

Please don't try to break the site, flood it with calls or messages, or get around its limits. We limit how often each visitor and phone can use it so it keeps working for everyone.
